# حفظ البرومبتات الأصلية
المجلد جاهز لاستقبال النصوص الكاملة. لم تُنشأ ملفات تشغيل فارغة توحي بوجود برومبتات مستوردة.

الوجهات عند الاستيراد:
- distillation/short/ وdistillation/long/
- writing/short/ وwriting/long/
- compression/
- images/
- motion/
- packaging/

تُنشأ المجلدات الفرعية عند إضافة أول ملف حقيقي إليها؛ Git لا يحفظ المجلدات الفارغة.
احتفظ بالاسم الأصلي، وسجّل المصدر والاعتماد في docs/PROMPT_INVENTORY.md.
لا تخلط تعليمات نسختين، ولا تستبدل النص الأصلي بملخص.
