# أمثلة الإنتاج
لا توجد أمثلة مستوردة بعد. لا تُعرض الأمثلة المصطنعة كنجاحات إنتاج.

لكل مثال حقيقي أنشئ مجلدًا باسم واضح، واحفظ:
- README.md: نوع الفيديو، نسخة المحرك ومعرّف commit، وحالة الاعتماد.
- approved-script.txt: النص المستخدم فعلًا.
- distillation.md: الناتج كما سُلّم، مع بوابات المراجعة.
- production-notes.md: ما أُضيف أو حُذف أو صُحح في المونتاج وسببه.

عند تقييم تعديل، استخدم النص نفسه للمقارنة. افحص التغطية والكشف والاستمرارية والتجزئة المفرطة؛ لا تحكم على الجودة بعدد الصور وحده.
