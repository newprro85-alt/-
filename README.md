# قصة ورسمة — أرشيف البرومبتات
برومنت تقطير متطور

أرشيف عملي لحفظ نصوص البرومبتات الأصلية، قواعد استخدامها، وسجل نسخها. هذا التنظيم لا يغيّر نظام التقطير ولا يعيد كتابة محركات الإنتاج.

## البداية
1. راجع [فهرس الملفات](docs/PROMPT_INVENTORY.md) لمعرفة الموجود وما ينتظر الاستيراد.
2. اقرأ [قواعد الاستخدام](docs/USAGE.md) و[حدود التقطير](rules/DISTILLATION.md).
3. اختر SHORT أو LONG والنسخة المعتمدة للمشروع؛ لا تدمج المحركات.
4. استخدم النص الأصلي الكامل عند استيراده، ثم احفظ مخرجات المشروع ومعرّف النسخة.

## بنية الأرشيف
| المسار | الغرض |

## الحالة الحالية
هذه دفعة توثيق أولية بتاريخ 2026-10-30. الملفات الجديدة إرشادات وفهرسة، وليست نسخًا بديلة من البرومبتات.
تم العثور على ملفات لونغ ومراجعة أجزاء محددة منها؛ لم تُستورد نصوص البرومبتات الكاملة بعد.
لم تُعيّن نسخة افتراضية للإنتاج. رقم الإصدار الأعلى أو تاريخ الملف الأحدث لا يثبت وحده اعتماد النسخة.

## ثوابت
- التقطير يحدد ما يظهر وترتيبه؛ توليد الصورة والحركة مرحلتان مستقلتان.
- الصورة حالة بصرية مجمدة، وليست سلسلة أحداث داخل إطار واحد.
- لا إعادة كتابة للـCompressor الحالي لمجرد التحسين.
- SHORT وLONG مساران منفصلان؛ تفضيل عدد صور الشورت لا يُنقل إلى اللونغ.
- اختلاف النسخ يُوثّق، ولا يُحل بدمج تعليماتها تلقائيًا.

راجع [مصادر التوثيق](docs/SOURCES.md) قبل نسبة قاعدة إلى نسخة بعينها.
